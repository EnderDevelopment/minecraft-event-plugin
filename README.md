# Eventos de Yaagaami

Eventos de Yaagaami is a Minecraft plugin designed to manage events within your server. It provides a set of commands to create, start, and finish events, making it easier for server administrators to organize and participate in various in-game activities. The plugin is built using the PaperMC API, ensuring compatibility and performance.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your server to load the plugin.

## Use

1. **Create an Event**: Use the command `/evento criar` to create a new event.
2. **Start an Event**: Use the command `/evento iniciar` to start the event.
3. **Finish an Event**: Use the command `/evento finalizar` to finish the event.
