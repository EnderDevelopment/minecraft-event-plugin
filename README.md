# Eventos de Yaagaami

Eventos de Yaagaami is a Minecraft plugin designed to manage and participate in various events on your server. This plugin allows server administrators to create, start, and end events, and provides players with the ability to participate in these events. The plugin includes features such as configuring event rules, managing event permissions, and interacting with event menus.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to load the plugin.

## Use

1. **Creating an Event**:
   - Use the command `/evento criar` to create a new event.

2. **Starting an Event**:
   - Use the command `/evento iniciar` to start the event.

3. **Ending an Event**:
   - Use the command `/evento finalizar` to end the event.

4. **Configuring Event Rules**:
   - Use the command `/evento gamerule` to open the event menu and configure rules such as block breaking and PvP.

5. **Participating in an Event**:
   - Players with the `evento.participar` permission can participate in events by following the event-specific instructions.
